# Aditya Mer — Portfolio (Next.js)

A fast, modern portfolio built with Next.js 16, React 19, Tailwind CSS v4, and Framer Motion. It showcases projects, experience, education, and research with a crisp, “funky” theme.

- Live: https://adityamer.live
- Repo: https://github.com/Aditya190803/Aditya190803.github.io

## Features
- Hero, About, Projects, Experience, Education, and Contact sections
- Animated UI with Framer Motion and a bold, “brutalist” visual style
- Single-source data model in src/lib/data.ts
- Clickable research authors with LinkedIn links
- Static‑ready build (prerendered pages)

## Tech Stack
- Next.js 16 (App Router) + React 19
- Tailwind CSS v4 + PostCSS
- Framer Motion, Lucide React
- Bun (preferred) or Node/npm
